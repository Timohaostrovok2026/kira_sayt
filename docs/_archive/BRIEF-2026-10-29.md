# «Улыбайся» — бриф для разработки

> Исходный бриф первого дня. Действующие правила — в `../../AGENTS.md` и `../../DESIGN.md`.
> Устарело: каталог больше не импортируется статически из `@/data/catalog` — используйте `useCatalog()` / `getCatalog()` (см. AGENTS.md, раздел 4).

Сайт агентства детских праздников Кирилла Мочалова (Москва и МО). Аниматоры в костюмах (110+ героев), квесты, вечеринки, шоу (крио, бумажное, неон, пузыри), мастер-классы, допы (фотограф, Reels), готовые пакеты.

## Цель
Не «красивая обёртка», а удобная воронка: клиент открыл → листает, свайпает, жмёт → собрал праздник в корзину → отправил заявку менеджеру в один клик, без 100 созвонов. Ярко, современно, быстро, «для СДВГ»: короткие тексты, крупные кнопки, ленты со свайпом, всё понятно за секунду. Антипример — lobacheva-project.ru (простыни текста, нет цен, перегруз).

## Стек
- Next.js 16.4 App Router, React 19.3, TypeScript, Tailwind CSS v4 (токены в `src/app/globals.css`, `@theme`).
- ВАЖНО: в Next 16 есть ломающие изменения. Перед кодом сверяйся с `node_modules/next/dist/docs/` (например, `params`/`searchParams` — это Promise, их надо `await`; `useSearchParams` требует `<Suspense>`).
- Иконки: `lucide-react` (брендовых иконок типа Instagram там нет).
- Картинки: `next/image`. Фото костюмов 480×640 webp: `costumeImg(id)` из `@/data/catalog`. Обложка программы: `programCover(id)`.
- Не запускай `next dev`/`next build` — один dev-сервер уже держит основной агент. Проверка: `npx tsc --noEmit` и `npx eslint <твои файлы>`.

## Дизайн-система (не добавлять новых акцентных цветов!)
- Один бренд-цвет — малиновый: `rasp-50…rasp-950`. Текст `ink`, вторичный `ink-soft`, фон `paper`, линии `line`. `star` — только для звёзд рейтинга/VIP.
- Классы: `.wrap` (контейнер), `.stage` / `.stage-soft` (тёмная малиновая сцена = фон студийных фото героев; на ней фото «сливаются» со страницей), `.h-hero`, `.h-section`, `.h-card`, `.eyebrow`, `.lead`, `.btn` + `.btn-primary|.btn-light|.btn-ghost|.btn-soft` + `.btn-sm|.btn-lg`, `.chip` (с `aria-pressed`), `.card`, `.rail` (горизонтальная лента со snap), `.price`, `.reveal` (+ хук `useReveal()` из `@/lib/useReveal`), `.pb-nav`.
- Шрифты: заголовки Unbounded (`font-display`), текст Onest. Основной текст 17px. Никакого КАПСА в заголовках.
- Mobile-first: проверяй на 375px. Поля 16px. Без горизонтального скролла страницы. Нижняя навигация на телефоне занимает `--bottom-nav-h` — `Footer` уже имеет отступ, но липкие элементы внизу экрана ставь выше неё: `bottom-[calc(var(--bottom-nav-h)+env(safe-area-inset-bottom)+8px)] lg:bottom-6`.
- Тёмный режим не делаем.
- Анимации — лёгкие (transform/opacity), уважаем `prefers-reduced-motion` (уже в globals.css).
