## 4. Технические решения Claude
| № | Решение | Почему | Дата |
|---|---|---|---|
| Т1 | Next.js 16 (App Router, `cacheComponents`), React 19, Tailwind 4 | Быстрый сайт с серверным рендером, один проект на сайт, админку и API | 2026-10-29 |
| Т2 | Контент и заявки в SQLite (`node:sqlite`), кэш с тегом `catalog` | Один сервер, без отдельной СУБД; правки из админки видны сразу | 2026-10-29 |
| Т3 | Своя аналитика `/api/track` + `/stats` | Метрики ещё нет; данные остаются у нас | 2026-10-29 |
| Т4 | Timeweb + Caddy, сертификат Let's Encrypt на IP | `sslip.io` блокировался у Кирилла; домена пока нет | 2026-10-29 |
| Т5 | Выкладка `deploy.sh`: rsync + кэш npm с Mac, база не трогается | С сервера недоступен npm-реестр; боевая база неприкосновенна | 2026-10-29 |
| Т6 | Все фото через `Photo` с малиновой заглушкой, нарезанные — без пережатия | Скорость на мобильном, нет «пустых» карточек | 2026-10-29 |
| Т7 | «Перетекание» фото между страницами убрано | ViewTransition в Next 16.4 не запускается; вернуться при обновлении | 2026-10-29 |
| Т8 | Git — в корне проекта (вместе с правилами и `docs/`), без `materials/` и `scratch/`. Старый `web/.git` (только стартовый коммит Next) — в `scratch/_archive/` | Правила, дизайн и документы должны версионироваться вместе с кодом; проверяющий `code-breaker` работает в копии репозитория | 2026-10-30 |
| Т9 | Одна команда проверки `npm run verify` (tsc + eslint + `node --test`); тесты рядом с кодом `*.test.ts`, Node сам понимает TypeScript | Механическая проверка за секунды перед каждым коммитом; без новых зависимостей | 2026-10-30 |
| Т10 | Хук `.claude/hooks/block-destructive.sh`: блок `rm -rf` (кроме `scratch/`, `.next`, папки сессии), `git push --force` (после раунда 6; обычный push разрешён), `reset --hard`, чтения `.env`/ключей, записи в боевую базу через ssh/scp, `DROP`/`DELETE` без условия | Правила AGENTS.md §3, §5 — механически, а не на честном слове | 2026-10-30 |
